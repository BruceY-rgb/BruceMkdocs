2. 筛选法求质数
```cpp
#include <iostream>
#include <algorithm>
#include <vector>

using namespace std;

vector<int> sieve(int n)
{
    if(n<2) return vector<int>();

    //初始化标记数组，默认所有数都是质数
    vector<bool> isPrime(n+1,true);
    isPrime[0]=isPrime[1]=false;

    //筛选法的核心：从2开始，遍历每个数，如果当前数是质数，则将其倍数标记为合数
    for(int i = 2;i*i<=n;i++)
    {
        if(isPrime[i])
        {
            for(int j = i*i;j<=n;j+=i)
            {
                isPrime[j]=false;
            }
        }
    }
    vector<int> primes;
    for(int i = 2;i<=n;i++)
    {
        if(isPrime[i])
        {
            primes.push_back(i);
        }
    }
    return primes;
}
int main(void)
{
    int n;
    cin>>n;

    vector<int> ans = sieve(n);

    cout<< ans.size()<<endl;
    for (int i = 0; i < ans.size(); i++) {
        cout << ans[i];
        if (i < ans.size() - 1)cout << " ";
    }
    cout << endl;

    return 0;
}

```

4. 在 C++ 中，`vector<string> v(10);` 定义了一个包含 10 个 `string` 元素的向量，每个元素会调用 `string` 的默认构造函数进行初始化。

我们需要分析每个选项，看看是否会调用 `string` 的构造函数。

---

### **选项分析**

#### **A. `v[0] += "abc";`**
- 这行代码是对 `v[0]` 的字符串内容进行追加操作。
- 不会调用 `string` 的构造函数，因为 `v[0]` 已经通过默认构造函数初始化。
- 会调用 `string` 的 `operator+=` 方法。

#### **B. `v[0] = "2018";`**
- 这行代码是将 `"2018"` 赋值给 `v[0]`。
- 不会调用 `string` 的构造函数，因为 `v[0]` 已经通过默认构造函数初始化。
- 会调用 `string` 的 `operator=` 方法。

#### **C. `v.push_back("ZUCC");`**
- 这行代码是向向量 `v` 的末尾添加一个新元素 `"ZUCC"`。
- 会调用 `string` 的构造函数，因为 `"ZUCC"` 是一个 C 风格字符串，需要将其转换为 `string` 对象。
- 具体来说，会调用 `string` 的 **构造函数**（接受 `const char*` 参数的构造函数）。

#### **D. `cout << (v[1] == "def");`**
- 这行代码是比较 `v[1]` 和 `"def"` 是否相等。
- 不会调用 `string` 的构造函数，因为 `v[1]` 已经通过默认构造函数初始化。
- 会调用 `string` 的 `operator==` 方法。

---

### **正确答案**
**C. `v.push_back("ZUCC");`**

---

### **详细解释**
- **`v.push_back("ZUCC");`**：
  - `"ZUCC"` 是一个 C 风格字符串（`const char*` 类型）。
  - 在将其添加到 `vector` 时，需要将其转换为 `string` 对象。
  - 这会调用 `string` 的构造函数，具体是 `string(const char*)`。

- 其他选项：
  - 选项 A 和 B 是对已经存在的 `string` 对象进行操作，不会调用构造函数。
  - 选项 D 是比较操作，也不会调用构造函数。

---

### **总结**
- 只有选项 C 会调用 `string` 的构造函数。
- 其他选项都是对已经存在的 `string` 对象进行操作，不会调用构造函数。

5. 有代码如下：
```cpp
int n;
string s;
cin>>n;
getline(cin, s);
cout<<s.size()<<endl;
```
则在输入以下数据后得到结果是（     ）。
```txt
1
Hello World
```
答案是 **B. 0**。

解析如下：
- 执行代码时，`cin >> n;` 会从输入中读取第一个整数 `1` 并存储到变量 `n` 中。
- 随后调用 `getline(cin, s);` 时，由于前一个输入（`cin >> n`）只读取了数字 `1`，但是输入缓冲区中仍然残留换行符 `\n`。`getline` 会直接读取到这个换行符并将其作为空字符串存储到变量 `s` 中。
- 因此，`s.size()` 的结果是 `0`，因为 `s` 是一个空字符串。

如果希望 `getline` 正常读取到 `"Hello World"`，需要在 `cin >> n` 和 `getline(cin, s)` 之间插入清除缓冲区的代码，例如 `cin.ignore();`。

For the code segment below, in the main(), 

- the output at //1 is `114`
- the output at //2 is `303062`
- the output at //3 is `115` 
- the output at //4 is `303062`
```cpp
class A{
    int i;
public:
    A(int ii=0):i(ii) { cout << 1; }
    A(const A& a) {
        i = a.i;
        cout << 2;     
    }
    void print() const { cout << 3 << i; }
};

class B : public A {
    int i;
    A a;
public:
    B(int ii = 0) : i(ii) { cout << 4; }
    B(const B& b) {
        i = b.i;
        cout << 5;
    }
    void print() const {
        A::print();
        a.print();
        cout << 6 << i;    
    }
};

int main()
{
    B b(2);        //1
    b.print();    //2
    B c(b);        //3
    c.print();    //4
}
```

??? tip "analysis"
    C++强制要求基类必须在派生类之前完全构造，所以即使子类中没有父类对象被显示定义，也会自动调用一次默认构造函数
