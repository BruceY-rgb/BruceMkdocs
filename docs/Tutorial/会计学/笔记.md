下列组织中
- 合伙企业 是会计主体不是法律主体
- 分公司 是会计主体不是法律主体
> 子公司既是法律主体也是会计主体
- 股份有限公司既是法律主体也是会计主体
- 母公司及其子公司组成的企业集团 是会计主体不是法律主体
- 销售门市部 是会计主体不是法律主体

2. 持续经营假设
- 含义：指在可以预见的将来，企业将会按当前的国模和状态持续经营下去，不会停业，也不会大规模削减业务
- 嘉定企业的经济活动能持续不断地进行。除非有明确的反证要终止经营活动
- 要求：持续经营状态与清算状态应采用完全不同的会计处理方法
> 如：固定资产在持续经营状态下采用立式成本法并进行正常折旧。而在清算状态下只能采用市场价值或评估价值
3. 会计分期假设
- 含义：指讲一个企业持续经营的生产经营活动划分为一个连续的、长短相同的期间
- 对会计主体持续经营的时间人为划分为几个阶段，以定期以揭示经营情况
- 看一个企业的好坏要看多个连续时期的财务报表
> 具体表现：定期编制财务报表以分清各个会计期间的经营业绩和经管责任、分期提供决策需要的信息。
4. 货币计量和币值不变假设

（1）货币计量假设：对会计信息表现形式所作的假定
- 含义：以货币作为会计要素的计量单位--能够对比
- 要求：确定人民币为记账的本位币：业务收支以外币作为计量单位的编制报表时，赢折算为本位币

（2）币值不变假设--货币计量的补充假设
- 含义：用作计量单位的货币，其购买力是固定不变的
> 十年前一块钱能买啥现在还能买啥

- 以货币计量的会计信息，其价值可以相互比较、综合计算
- 由于报表能反映的经济活动都是能以货币计量的经济活动，只能体现财务信息。根据报表信息决策有一定缺陷，不能反映非货币化信息。比如人才资源的信息无法在报表上体现。
- 要求：以**历史成本**作为计量的基本依据
> 除非出现明显的通货膨胀

## 第四节 会计信息质量要求
1. 可靠性
- 基本含义：会计信息及会计所确认的经济活动必须客观真实
- 主要要求：①会计核算应当以**实际**发生的经济业务为依据；②会计人员应客观公正
> 所有记账的必须有会计凭证，将要发生的经济活动不能计在账上
2. 相关性
- 基本含义：会计所提供的信息必须与使用者的经济决策有关
- 主要要求：充分考虑信息能有助于使用者对企业过去、现在及未来的客观评价。根据准则、制度要求提供信息。

相关性和可靠性是最基本的两大要求，但是在某些情况下二者是矛盾的。
> 计提资产减值：企业根据会计准则的要求，对可能发生减值的资产进行评估，并在财务报表中提前确认其价值损失的过程，以确保财务报表的真实性，避免高估资产和利润。这是不符合可靠性(以历史价值记账)的但是符合相关性。

3. 可比性（含一贯性）

- 横向可比与纵向可比
    - 纵向可比：会计处理的*方法*应当前后一致（时间上的一致性）
        - 方法：先进先出法；加权平均法等。方法不同产生的成本不同。
    - 横向可比：不同会计主体之间的信息应互相可比
- 基本含义：会计处理的方法应当**前后期**一致，不同会计主体的信息应互相可比
- 主要要求：①不得随意改变会计处理的程序方法；②确有必要改变，应说明原因及其对财务状况、经营成果的影响；③不同会计主体对同类会计事项应采用相同的会计方法
4. 可理解性（按照制度准则提供信息）
- 基本含义：会计记录和报表应清晰明了，便于理解和运用
- 基本要求：提供的信息应通俗易懂，使用者通过分析信息能了解企业
5. 及时性
- 基本含义：按照规定期限及时记录和提供财务信息
- 基本要求：①本期事项应在本期全部确认记录；②按规定时间编报报表
6. 重要性
- 基本含义：会计应记录提供一切有用的重要信息
- 基本要求：在财务处理中，重要信息应严格处理、单独列
> 重要信息：金额重要（不一定与金额大小与直接关系，与其性质也有直接关系，盈利or亏损）
7. 实质重于形式
- 基本含义：要求按照业务的实质进行会计核算
- 基本要求：不应当仅仅按照业务的形式
> 售后回购不能被确定为销售行为
8. 谨慎性
- 基本含义：对于收入、费用处理持稳健态度
- 基本要求：①不应该低估负债、费用②不应高估资产、收入
> 以相对低调的态度处理报表，资产不要高估，消费不要低估

## 第五节 会计确认的基础

***权责发生制原则（应计制）***
1. 涵义：费用应当在收入权利、费用责任形成期间予以确认二不论该期间是否收到或付出现金
- 收入看权利，费用看责任。不看钱什么时候给
2. 要求：跨期的收入费用，应采用特殊程序和方法记录和分配
3. 收付实现制：以现金的实际收付期作为标准确认当期收入与费用

## 第六节 会计计量属性
### 一、会计计量属性的类别
1. 历史成本：又称为实际成本。即取得或制造某项财产物质时所实际支付的现金或其他等价物
2. 重置成本又称为现行成本，是指按照当前市场条件，重新取得同样一项资产所需支付的现金或现金等价物金额 
- 账实一致：通过盘点得到实际数，要根据市场价进行落账
3. 可变现净值（可预计的现金净流入）：是指在正常生产经营过程中，以***预计售价***减进一步加工成本和销售所必须的预计税金、费用后的净值
4. 公允价值：市场参与者在计量日发生的有序交易中，出售一项资产所能收到或者转移一项负债所需支付的价格
- 有序交易：惯常的公平的交易
- 公允价值也就是脱手价格，具体应用于交易性金融资产初始计量及后续计量（如股票）

### 二、会计计量属性的应用原则
- 一般采用历史成本计量，采用重置成本、可变现净值以及公允价值计量的，应当保证所确定的会计要素金额能够取得并可靠计量
